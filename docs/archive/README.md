# Archive

Historical material kept for provenance. Nothing here describes the current state of the project;
see `CLAUDE_PROJECT_STATUS_AND_NEXT_STEPS.md` at the repository root for the verified status.

- `session-notes-2025-10/` — per-session status notes, API-provider research, test guides and git
  summaries written between 2025-09-24 and 2025-10-16 (originally loose files at the repository root).
  API keys, test credentials and personal e-mail addresses were redacted before these files were committed
  (`<..._REDACTED>` markers). Several files carry a wrong "January 2025" date stamp; file history and
  the assessment report give the real timeline.
- `legacy-test-pages/` — throw-away HTML/JS test harnesses for third-party football APIs and an
  architecture diagram component. They are not part of the application build.

Current product requirements live in `docs/requirements/`.
